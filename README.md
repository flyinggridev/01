# Flying Grid Website

A responsive, single-page English landing website for Flying Grid's two-wheeler EV charging station partnership program.

## Files

- `index.html` — complete website (HTML, CSS and JavaScript in one file)
- `logo.png` — the Flying Grid logo supplied for this website

## Run locally

Keep `index.html` and `logo.png` in the same folder. Open `index.html` in a browser.

## Publish using GitHub Pages

1. Create a GitHub repository, for example `flying-grid-website`.
2. Upload `index.html` and `logo.png` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish the website. The public URL will appear in the Pages settings.

- Google Fonts also require an internet connection; system fonts will be used if they cannot load.
- The website describes the no-investment offer as subject to site feasibility and the final written partnership agreement. Make sure the commercial terms accurately reflect your actual offer.
